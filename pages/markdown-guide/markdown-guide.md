# A Markdown Formatting Guide

This post doubles as lorem ipsum filler and a live demo of every Markdown
element the theme styles. Swap in your own words once you are comfortable.

## Headings

Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor
incididunt ut labore et dolore magna aliqua.

### A third-level heading

Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut
aliquip ex ea commodo consequat.

## Lists

- Duis aute irure dolor in reprehenderit in voluptate
- Velit esse cillum dolore eu fugiat nulla pariatur
  - Nested item one
  - Nested item two

1. First ordered item
2. Second ordered item
3. Third ordered item

## Code

Inline `code` looks like this. A fenced block is styled too:

```ruby
def greet(name)
  puts "Hello, #{name}!"
end
```
